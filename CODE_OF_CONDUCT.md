# Code of Conduct

RoIM brings together architects, engineers, contractors, roboticists and researchers. We want everyone to be able to take part.

**Expected**
- Be respectful and assume good intent.
- Critique ideas, not people. Back claims with evidence where you can.
- Welcome newcomers and different disciplines; explain jargon.
- Respect confidentiality: don't post client data, project names or models you don't have the right to share.

**Not acceptable**
- Harassment, insults or discriminatory language
- Personal attacks or trolling
- Publishing others' private information
- Promotional spam

**Enforcement.** Maintainers may edit, hide or remove contributions that break this code, and may block repeat offenders. Report concerns privately to the maintainer through GitHub.

This code is adapted in spirit from the Contributor Covenant.
